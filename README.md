# Personal Finance App

Aplicación para gestionar las finanzas personales de forma sencilla y centralizada.

## Entorno de desarrollo

El backend utilizará Java 21 y Git para el control de versiones. Codex CLI será la herramienta de trabajo para apoyar el desarrollo.

Verifica el entorno con:

```bash
java -version
git --version
codex --version
```

## Arranque

Los comandos de arranque se documentarán cuando exista el proyecto Spring Boot.
